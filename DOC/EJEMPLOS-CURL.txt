═══════════════════════════════════════════════════════════════════
  3️⃣  PROBAR MCP SERVER (JSON-RPC 2.0)
═══════════════════════════════════════════════════════════════════

# 3.1 Listar Tools via JSON-RPC
curl -X POST http://localhost:3001/rpc ^
  -H "Content-Type: application/json" ^
  -d "{\"jsonrpc\":\"2.0\",\"method\":\"tools/list\",\"id\":1}"

# 3.2 Ejecutar Tool: buscar_cliente por ID
curl -X POST http://localhost:3001/rpc ^
  -H "Content-Type: application/json" ^
  -d "{\"jsonrpc\":\"2.0\",\"method\":\"tools/call\",\"params\":{\"name\":\"buscar_cliente\",\"arguments\":{\"id\":1}},\"id\":2}"

# 3.3 Ejecutar Tool: buscar_cliente por nombre
curl -X POST http://localhost:3001/rpc ^
  -H "Content-Type: application/json" ^
  -d "{\"jsonrpc\":\"2.0\",\"method\":\"tools/call\",\"params\":{\"name\":\"buscar_cliente\",\"arguments\":{\"nombre\":\"Juan\"}},\"id\":3}"

# 3.4 Ejecutar Tool: buscar_cliente por email
curl -X POST http://localhost:3001/rpc ^
  -H "Content-Type: application/json" ^
  -d "{\"jsonrpc\":\"2.0\",\"method\":\"tools/call\",\"params\":{\"name\":\"buscar_cliente\",\"arguments\":{\"email\":\"maria.garcia@ejemplo.com\"}},\"id\":4}"

# 3.5 Ejecutar Tool: validar_disponibilidad
curl -X POST http://localhost:3001/rpc ^
  -H "Content-Type: application/json" ^
  -d "{\"jsonrpc\":\"2.0\",\"method\":\"tools/call\",\"params\":{\"name\":\"validar_disponibilidad\",\"arguments\":{\"fechaReserva\":\"2026-01-30T10:00:00Z\",\"duracionMinutos\":60}},\"id\":5}"

# 3.6 Ejecutar Tool: crear_reserva
curl -X POST http://localhost:3001/rpc ^
  -H "Content-Type: application/json" ^
  -d "{\"jsonrpc\":\"2.0\",\"method\":\"tools/call\",\"params\":{\"name\":\"crear_reserva\",\"arguments\":{\"clienteId\":1,\"servicioNombre\":\"Corte de cabello\",\"fechaReserva\":\"2026-01-30T10:00:00Z\",\"duracionMinutos\":60,\"notas\":\"Cliente prefiere estilo clásico\"}},\"id\":6}"

# Paso 5: Verificar reserva creada
curl http://localhost:3003/reservas


───────────────────────────────────────────────────────────────────
  CASO 2: Probar Idempotencia (Prevención de Duplicados)
───────────────────────────────────────────────────────────────────

# Crear reserva con clave de idempotencia
curl -X POST http://localhost:3003/reservas ^
  -H "Content-Type: application/json" ^
  -H "X-Idempotency-Key: test-key-12345" ^
  -d "{\"clienteId\":1,\"servicioNombre\":\"Corte de cabello\",\"fechaReserva\":\"2026-03-15T10:00:00Z\",\"duracionMinutos\":60}"

# Ejecutar EXACTAMENTE el mismo comando otra vez
# Deberías recibir la MISMA respuesta sin crear una nueva reserva
curl -X POST http://localhost:3003/reservas ^
  -H "Content-Type: application/json" ^
  -H "X-Idempotency-Key: test-key-12345" ^
  -d "{\"clienteId\":1,\"servicioNombre\":\"Corte de cabello\",\"fechaReserva\":\"2026-03-15T10:00:00Z\",\"duracionMinutos\":60}"

═══════════════════════════════════════════════════════════════════
  🚨 SOLUCIÓN DE PROBLEMAS
═══════════════════════════════════════════════════════════════════

Problema: "GEMINI_API_KEY no configurada"
Solución: 
  1. Edita .env con tu API Key real
  2. docker-compose restart api-gateway

Problema: "No se pudo conectar con el MCP Server"
Solución:
  1. docker ps (verificar que mcp-server esté corriendo)
  2. docker-compose logs mcp-server

Problema: Contenedor no inicia
Solución:
  1. docker-compose logs [nombre-servicio]
  2. docker-compose down
  3. docker-compose up --build -d

Problema: Puerto ya en uso
Solución:
  1. docker-compose down
  2. Cerrar aplicaciones que usen puertos 3000-3003
  3. docker-compose up -d
